Calculation audit & standards scope

Release 3.1 · Review date: 20 September 2026

Audit conclusion

The implemented mathematical models were reviewed and tested within their stated scope. Full IEC or ANSI/IEEE compliance has not been established. This release must not be presented as a certified short-circuit, breaker-duty, protection or installation-design package.

This is a code, numerical-method, export and standards-gap review. Official catalogue scopes and public engineering references were consulted. Full licensed normative texts, manufacturer models, site data and independently validated reference-software outputs were not available. A clause-by-clause standards conformance audit remains incomplete.

IEC and ANSI/IEEE study procedures are separate methods, not interchangeable labels for the same current calculation. No cosmetic IEC/ANSI selector has been added.

Website address finding

The production address returned HTTP 200 and version 2.1 during this review: energyandpowersolutions.netlify.app. It did not return an HTTP redirect to a random address. The complete alternate URL seen on the phone was not provided, so its exact origin could not be verified.

The v3.1 package redirects any other *.netlify.app hostname to the fixed production address, preserving path/query/fragment. It also displays a permanent public link and a Copy website link button. Local testing and the production address do not redirect. Old immutable deployment copies do not acquire these changes.

Publish this package as the production deploy of the existing energyandpowersolutions project. Publishing a new project or only opening a deployment permalink will not update the main site. Confirm “v3.1” at the main address after deployment. JavaScript must be enabled for the alias redirect; the short address remains directly usable without relying on a redirect.

Verification evidence and limits

Automated verification covers 1,920 dispatch cases across four modes and three strategy inputs; power/energy balance, SOC/current limits and per-unit generator limits. Study benchmarks cover an independent closed-form resistive two-bus solution, lossless network, transformer fault-current example, source/cable impedance effects, generator capacity and PF correction. Regression checks cover malformed inputs and invalid topology.

DOM-based checks cover navigation, inputs, CSV import, save/reopen, legacy projects, business settings and PDF/XLSX generation for all five studies. XLSX outputs are independently read by openpyxl; PDFs are parsed and representative pages inspected. URL logic is tested for canonical, deployment, unrelated Netlify, localhost and external hosts. These tests do not constitute standards certification or exhaustive verification of all numeric input combinations.

Phone layout was corrected after the supplied screenshots. No new real-device Safari run or independent ETAP benchmark was performed for v3.1. Full network/duty verification requires licensed applicable standards, verified equipment/site data, reference cases, and review by the responsible engineer. In particular, do not use the present fault estimate alone to approve breaker interrupting or making ratings.
